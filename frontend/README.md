# frontend

React + TypeScript + Vite single-page app for the Stress Leaderboard project. See the [root README](../README.md) for setup and how this talks to `api.py`.

```bash
npm install
npm run dev
```

## Linting

Uses [Oxlint](https://oxc.rs). For type-aware rules, install `oxlint-tsgolint` and set `"typeAware": true` in `.oxlintrc.json` — see the [Oxlint rules documentation](https://oxc.rs/docs/guide/usage/linter/rules).
